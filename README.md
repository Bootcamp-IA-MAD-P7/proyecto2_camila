# 🍽️ API Restaurante Buffet - FastAPI + Supabase

Objetivo del proyecto

Este proyecto tiene como objetivo desarrollar una API REST para la gestión de productos de un restaurante tipo buffet.

La API permite administrar los productos del menú (como platos, bebidas o complementos) utilizando FastAPI como backend y Supabase (PostgreSQL) como base de datos en la nube.

El objetivo principal es aprender cómo funciona una arquitectura backend real con operaciones CRUD conectadas a una base de datos externa.

Tecnologías usadas

- Python
- FastAPI
- Supabase (PostgreSQL)
- Uvicorn

Funcionalidades

- Crear productos del buffet
- Listar productos disponibles
- Obtener producto por ID
- Actualizar información del producto
- Eliminar productos del sistema
